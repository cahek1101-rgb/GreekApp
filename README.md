# GreekApp

Персональные карточки для изучения греческих слов и фраз перед собеседованием.

## Возможности

- 148 слов и фраз в 12 тематических колодах и отдельной колоде «Ядро».
- Два направления: греческий → русский и русский → греческий.
- Русская транскрипция, формы слов, устойчивые сочетания и примеры.
- Озвучивание греческого текста средствами устройства.
- Прогресс хранится на устройстве; его можно скопировать и восстановить.
- После первого открытия приложение работает без интернета.
- Устанавливается на iPhone как PWA, без App Store.

## Установка на iPhone

1. Откройте ссылку в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран “Домой”».
4. При необходимости измените название и нажмите «Добавить».

Приложение появится на домашнем экране с собственной иконкой и будет открываться без интерфейса браузера.

## Публикация через GitHub Pages

В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, затем **main** и **/(root)**. После сохранения публикация обычно занимает несколько минут.
